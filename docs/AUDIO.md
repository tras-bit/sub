# SUBSISTENCE — звук и анимации (1.0.0-alpha)

## Принцип: ноль аудиофайлов

В игре **нет ни одного .wav/.ogg** — все 23 клипа считаются математикой в рантайме
(`Scripts/Audio/ProcAudio.cs`, PCM 22 050 Гц) и кэшируются в памяти. Почему так:

* архив остаётся 27 МБ вместо «+100 МБ сэмплов»;
* любой параметр звука правится кодом (частота гула, длина шёпота, фильтр шага);
* нет проблем с лицензиями на библиотеки звуков.

**Музыки и радио в игре нет вообще** (ответ 16а): ни «музыки погони», ни приёмников —
только атмосфера уровня, шаги, гул ламп, капель, рык и крики монстров. Музыкальный слой
в проекте отсутствует на уровне кода: в `AudioDirector` нет ни одного вызова с музыкой,
и это закреплено комментарием, чтобы механику не вернули по ошибке.

Если позже захочешь «ультра-реализм» на слух — кладём .wav в `Assets/Subsistence/Audio/…`
и подменяем в `AudioDirector` (интерфейс `PlayAt/Play2D` уже готов), код игры не меняется.

## Где это подключено (`Audio/AudioDirector.cs`)

* **Пул из 20 позиционных источников** (Linear rolloff, 2 → 55 м) + 1 канал 2D для
  интерфейса. Никаких `Instantiate` на каждый выстрел.
* `PlayerFootsteps` — шаги по пройденному пути (0.85 м, на бегу 1.25×), выбор клипа:
  тема уровня (`LevelZone`) + вода (`WorldEnvironment.IsUnderwater`).
* `MonsterAudio` — шаги монстра, характерные звуки вида (шёпот каждые 16 с, капли 6 с,
  треск 8 с), рычание при погоне (`MonsterState.Chase`), крик при смерти.
* `LevelAmbience` — два зацикленных источника, кроссфейд 0.25 с при смене уровня:
  L0 гул ламп 0.22 · L37 еле слышно 0.06/0.05 · L3 трансформатор 0.30.
* Клипы дёргаются из: `Weapons` (выстрел/перезарядка/попадание), `BuildSystem`
  (постановка), `BuildHammer` (апгрейд/ремонт/снос), `ItemPickup`, `CraftingSystem`.

## Процедурная анимация монстров (`AI/MonsterMotion.cs`)

В моделях нет костей, поэтому «жизнь» даётся смещением визуального меша — сам объект,
коллайдер, физика и сеть не трогаются:

* **шаг:** покачивание по высоте (bob 5.5 см) + крен вбок до 5.5° + наклон вперёд 6.5°
  на бегу; темп фазы 2.2 → 8.5 рад/с по фактической скорости;
* **покой:** «дыхание» 1.5 Гц, амплитуда 1.2 см;
* **по виду:** Шептун тянется вперёд и качается боком сильнее (×1.6), Утопленник
  валится с боку на бок (×2.2) почти без подпрыгивания, Искровик дрожит
  (шум Перлина 24–26 Гц), Гончая почти не наклоняется;
* **смерть:** заваливание на 82° с оседанием за 0.6 с.

Превью — `docs/previews/_anim_MN_*_0..3.png` (покой / шаг влево / шаг вправо / смерть).

## Что можно докрутить (следующим шагом)

1. Отдельный слой «шаги по лужам» с реальным сэмплом воды (процедурный чавк хорош, но
   сэмпл всё же узнаваемее) — подмена в один вызов.
2. Реверб по зонам: в бассейнах эхо длиннее, в коридорах короткое (сейчас общий ambient).
3. Анимация монстров по фазам ИИ: замах перед ударом, «принюхивание» в Investigate.
4. Озвучка действий игрока: вдох-выдох при беге, кашель при инфекции (данные уже есть в `SurvivalState`).
