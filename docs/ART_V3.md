# SUBSISTENCE — арт-проход v3 (оружие заново + уникальные вещи уровней)

Дата: 2026-09-13. Причина: v2-оружие читалось как «склейка кубиков» (ствольная коробка —
плита, магазин — лестница из смещённых брусков, приклад — три отдельных доски).
Переделано с нуля, процедурно, в Blender (bpy 5.2.1, headless, Cycles CPU).

## 1. Новый инструмент формы — `tools/blender/subs_shapes.py`

То, чего не хватало: не «домики из кубов», а настоящие силуэты и лофт по сечениям.

| Функция | Что делает | Где применяется |
|---|---|---|
| `profile(name, pts, width)` | 2D-силуэт (вид сбоку) → объёмная деталь | ресиверы, приклады, рукоятки, ложе, лезвия сошек |
| `loft(name, sections)` | сшивка колец сечений в трубу | стволы с уступом, кожухи, баки |
| `loft_path(name, path, w, h)` | кольца вдоль КРИВОЙ с доворотом | магазины (АК/STANAG/MP5), боеголовка РПГ |
| `ring_rect / ring_circle / ring_round` | сечения: прямоугольник со скруглением, круг, эллипс | всё |
| `tube_between(p0, p1, r)` | цилиндр между точками | сошки, рукоять затвора, поручни, провода |
| `ring_torus(...)` | тор | намушник, чека гранаты, штурвал вентиля, круги |
| `mag_loft(...)` | магазин: путь сам идёт вниз и вперёд, сечение = толщина×глубина | все магазины |

Плюс режим самопроверки: `--check` печатает габариты КАЖДОЙ детали и ругается на
оторванные (именно так нашлись: магазин-«лезвие», пламегаситель M4, улетевший на
28 см из-за поворота вокруг мирового центра, и ступица сошек).

## 3. Свои вещи для каждого уровня — `tools/blender/models_levels.py`

27 моделей, разделены по уровням, друг с другом не пересекаются:

* **L0 «Жёлтые коридоры»** — панель с обоями и плинтусом, лампа дневного света,
  офисный стул на крестовине, картотека с ящиками и ручками, кулер с бутылью,
  стопка коробок со скотчем, швабра с ведром, табличка EXIT (светится), вентилятор.
* **L37 «Бассейны»** — лестница в бассейн, спасательный круг с полосами и верёвкой,
  лежак с 16 планками, насос с фильтром и манометром, труба с фланцем и штурвалом,
  душевая лейка с отверстиями, знак «мокрый пол», панель кафеля 6×3, надувной круг.
* **L3 «Электростанция»** — корпус турбины с венцом болтов и лопатками, щит управления
  с приборами и тумблерами, трансформатор с рёбрами и изоляторами, шкаф рубильников,
  труба с фланцем, колесо-вентиль, бак охлаждения с лестницей, кабельный барабан,
  знак на ржавой стойке.

Палитры тоже разные: L0 — обои/ковролин/бежевый пластик; L37 — кафель, хром, вода,
оранжевый «спасательный»; L3 — бетон, чугун, ржавчина, медь, зелёная краска, жёлтый.

## 4. Что изменилось в игре (C#)

* `ModelLibrary.Names` — 27 новых имён `LV_*`.
* `ModelLibrary.LevelProps` — таблица «своё для каждого уровня» + `For(LevelTheme)`.
* `LevelGenerator`: `SpawnProp(...)` теперь **ставит реальную модель** (AttachFitted),
  а куб остаётся коллайдером/фолбэком; в `DecorateCorridors` / `DecoratePoolrooms` /
  `DecoratePowerStation` добавлено по 16 расстановок из своего набора.
  Раньше декор был кубами-заглушками — это и было главной причиной «уровни одинаковые».

## 5. Как пересобрать всё самому

```bash
# одна модель
python3 tools/bpy_run.py tools/blender/models_weapons.py -- --only W_rifle_ak
# все стволы (+ FBX/GLB и превью в docs/previews)
python3 tools/bpy_run.py tools/blender/models_weapons.py
# вещи уровней
python3 tools/bpy_run.py tools/blender/models_levels.py
# диорамы «как это выглядит»
python3 tools/bpy_run.py tools/blender/models_levels.py -- --diorama
# проверка «ничего не оторвалось»
python3 tools/bpy_run.py tools/blender/models_weapons.py -- --check
# сводные листы превью
python3 tools/make_sheets.py weapons
python3 tools/make_sheets.py level L0
```

`tools/setup_blender.sh` поднимает Blender в чистой песочнице (bpy уже стоит в образе,
но кэш `~/.cache` не переживает рестарт — нужен `provision_libs.py`).

## 6. FBX/GLB в Unity

Файлы кладутся в `Assets/Subsistence/Models/{Weapons,Props}`. Пункт меню
`Subsistence → 7. Собрать префабы моделей` (или автонастройка при первом открытии)
сканирует папку `Models` и собирает префабы в `Resources/Models/<Имя>.prefab`,
откуда их берёт `ModelLibrary`. Названия префабов должны совпадать с именами
констант в `ModelLibrary.Names` — они совпадают.

## 7. Монстры уровней (v4, 2026-09-14)

Появились три «своих» монстра — по одному хозяину на уровень. Модели на новом инструменте
(`tools/blender/models_monsters3.py`): **всё в абсолютных координатах**, через `loft_z`
(стек колец по высоте) + `tube_between` — те самые `location`/`rotation_euler`, из-за
которых фигуры разъезжались, здесь не используются вообще.

| Вид | Уровень | Образ | Жизни | Особенность | Звук |
|---|---|---|---|---|---|
| `MN_whisperer` | L0 | вытянутый, руки до колен, пасть-щель, светящиеся глаза | 140 | `canLoseTarget = false`, идёт на свет | шёпот-манить (радиус 34 м, раз в 16 с) |
| `MN_drowned` | L37 | раздутый, сгорбленный, голова клюёт вниз, вода из пасти, водоросли | 320 | медленный (1.5/3.4 м/с), толстый | мокрые шаги (22 м, раз в 6.5 с) |
| `MN_spark` | L3 | обгоревший, провода вместо мышц, один глаз, искрящая грудь | 190 | быстрый (4.4/8.2 м/с), урон = взрыв (ток) | треск электричества (18 м, раз в 9 с) |

* `AI/Monsters.cs`: +`Whisperer/Drowned/Spark` в `MonsterDef`/`MonsterTable`, высоты моделей,
  радиусы капсул, метод `Flavor()` — «голос» вида через `NoiseSystem.Emit`.
* `World/LootSpawner.cs`: свои таблицы дропа — `monster.whisperer / .drowned / .spark`.
* `Runtime/RuntimeBootstrap.cs`: волны по уровням переписаны — на каждом уровне минимум
  два своих вида; первичный спавн: каждый третий — «специалист».

Превью: `docs/previews/_sheet_monsters.png` (все виды с подписями).
