# SUBSISTENCE — Game Design Document v0.1

> **Формула:** механики Rust (строительство, рейды, прочность, лут, крафт) × атмосфера и монстры Backrooms,
> три уровня = три тира лута. 100+ игроков на сервер, 30 Гц серверный тик, HDRP.

## 1. Ядро геймплея (core loop)

```
Загрузка в Level 0 «Жёлтые коридоры» (Tier 1 лут)
   │ камень/факел/план → первые инструменты, мини-база
   ├──► добыча дерева/камня (кирка, топор) → стройка базы (twig → wood → stone)
   ├──► обыск ящиков/шкафов → самопал, дробовики, хазмат
   ▼
«Провал» / лестница → Level 37 «Бассейны» (Tier 2)
   │ вода, эхо, гончие; нужен очиститель воды и апгрейд до metal
   ├──► ПП/карабины, roadsign-броня, синяя ключ-карта
   ▼
Level 3 «Электростанция» (Tier 3)
   │ радиация (нужен хазмат), Свежеватели, реакторный зал, ТВЭЛ-кассеты
   ├──► AK/M249/RPG, металл-броня, C4, красная ключ-карта, ТВЭЛ
   ▼
ЭНДШПИЛЬ: 3 ключ-карты + ТВЭЛ → «выход» → серверное событие (объявление в чат, вайп зоны)
```

**Петли по длительности**

| Горизонт | Что игрок делает | Механики |
|---|---|---|
| 30 секунд | идёт по коридору, прислушивается | гул ламп, шаги, свет фонаря |
| 5 минут | обыскивает комнату, режет монстра | лут-таблицы, бой, износ оружия |
| 30 минут | ставит базу, крафтит верстак 1 | стройка, апкип, TC |
| 3 часа | рейд на чужую базу, добыча HQM | C4/сачель, тиры блоков, ловушки |
| 3 дня | апгрейд базы до armored, турели, SAM | upkeep, электрика, ловушки |
| 2 недели (вайп) | собирает эндшпиль, выходит | ключ-карты, босс, событие «выход» |

## 2. Дизайн-цели (и как код их выполняет)

1. **«Страшно, но по-растовски честно».** Смерть = потеря лута на землю (`PlayerEntity.DropLootBag`).
2. **Хардкорная экономика.** Нет респавна в базе без кровати/мешка (`SleepBag`), крафт гейтится верстаками 1–3.
3. **Укрытие имеет цену.** `ToolCupboard` (авторизация + апкип) + `DecaySystem` — брошенные базы гниют.
4. **Каждый шум — риск.** `NoiseSystem` + слух монстров: выстрел из AK слышно на 380 м (`WeaponStats.soundRadius`).
5. **Свет — двойственный.** Лампы/факелы выручают в темноте, но Smiler идёт на свет.
6. **Три тира без гринда «ради гринда».** Высокий тир физически на другом уровне — надо рискнуть спуститься.

## 3. Уровни

### Level 0 — «Жёлтые коридоры» (Tier 1)
- Геометрия: сетка 6 м, коридоры 2 клетки шириной, комнаты, квадратные колонны, потолок 3.2 м.
- Материалы: жёлтые обои (большая часть стен), ковролин, панельный потолок + решётчатые лампы каждые 12 м.
- Свет: 0.85 intensity, flicker 2 %/с, фон-гул ламп (маскирует шаги — самое ценное).
- Данж-контент: ящики, архивные шкафы, бочки; записки-«камера» (фотоаппарат — мини-квест на 3 кадра).
- Опасность: Smiler (идут на свет), легко заблудиться в одинаковых коридорах.
- Выходы в Level 37: 3 шахты на разных концах карты (лестница + провал).

### Level 37 — «Бассейны» (Tier 2)
- Геометрия: залы 18×18 м, плитка 1×1 м, бортики, вода глубины 0.4–2.6 м (объёмы + триггеры).
- Вода: замедление, шум (шаги в воде слышны ×1.8), переохлаждение, запас воздуха 5 с, «хлорированная вода» пить можно, но риск инфекции.
- Эхо: `WorldEnvironment.NoiseSources` усиливают слышимость — здесь нельзя бегать тихо.
- Данж-контент: насосные, шкафчики, аптечки, аирдроп «грузовой контейнер» (топ-лут, приманка).
- Опасность: Hound (6.8 м/с погоня!), Partygoer (видит на 360°), Clump (400 HP ходячая гора).
- Ключ: синяя ключ-карта открывает закрытые насосные с Tier 2+ лутом.

### Level 3 — «Электростанция» (Tier 3)
- Геометрия: бетонные залы, турбины, щитовые, трубы Ø0.25–0.8 м, кабельные лотки.
- Радиация: реактор 12 рад/с вблизи, разливы ОЖ 4 рад/с, фон по залам. Без хазмата — смерть за ~2 минуты.
- Данж-контент: электрощиты, сейфы, военные ящики; красная ключ-карта.
- Опасность: Skin-Stealer (55 dmg, маскируется), радиация в реакторном зале (нужен хазмат/экзоскелет).
- Эндшпиль: ТВЭЛ + 3 карты → пульт «выход».

## 4. Монстры

| Монстр | Уровень | HP | Урон | Скорость | Особенность |
|---|---|---|---|---|---|
| Smiler | L0 | 120 | 18 | 4.2 | идёт на свет, одиночка, бьёт из темноты |
| Hound | L1 | 90 | 24 | 6.8 | быстрее игрока — нельзя убежать, только отстрел |
| Partygoer | L1 | 150 | 30 | 5.0 | угол зрения 360°, слышит на 70 м, стайный |
| Clump | L1 | 400 | 40 | 3.6 | ходячий «стенобой», ломает двери |
| Skin-Stealer | L3 | 200 | 55 | 6.2 | маскировка, атакует только вблизи |

Правила боя: пули λ≈1.0, огонь ×1.5 (единственный «правильный» контр), взрыв ×1.25.
Монстры получают урон от **своих** взрывов? Нет — сознательно: игрок не сможет «рейдить» монстров зарядами бесплатно.
Босс Bacteria отменён по ответам опросника — модель осталась в архиве моделей.

## 5. Соответствие механик Rust ↔ Backrooms

| Механика Rust | В SUBSISTENCE | Отличие |
|---|---|---|
| Building 2.0 | `Building/BuildSystem.cs` | 5 тиров, стабильность 24, обвал 3 с |
| Tool Cupboard + upkeep | `ToolCupboard`, `DecaySystem` | радиус 16 м, апкип по дереву/камню/металлу |
| Прочность и ремонт | `ItemStack.Wear/Repair` | ремонт −25 % качества каждого раза |
| Рейд (C4/сачель) | `Explosives.cs`, `RaidTable` | те же цифры: C4 550 по базе, satchel 275 |
| Потеря лута при смерти | `PlayerEntity.DropLootBag` | мешок может забрать убийца |
| Вода/еда/радиация | `Survival.cs` | жажда/голод, вода из бассейнов, обеззараживание, радиация — хазмат |
| Оружие/модификации | `Weapons.cs`, `AttachmentTable` | 6 слотов, 9 модов, реальные паттерны отдачи |
| Монстры = учёба у NPC | Smiler/Hound/Partygoer | + агрессия по свету и шуму |

## 6. Целевые метрики

- Сервер: 100 игроков, 30 Гц тик, ≤ 12 Мбит/с на игрока, снапшоты 20 Гц, AOI 32×32 м.
- Контент: 3 уровня, 140+ предметов, 5 монстров + босс, 12 типов блоков × 5 тиров, 80+ рецептов.
- Производительность: ≤ 3500 draw call, CPU сервера ≤ 60 % на 8 vCPU при 100 игроках.
