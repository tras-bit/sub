# SUBSISTENCE — Asset Bible (модели, текстуры, пайплайн)

> Реальность: в чат-песочнице нельзя «нарисовать» арт уровня Rust. Поэтому пайплайн такой:
> **уникальное генерируется моими Blender-скриптами** (уже сделано: 35 FBX в проекте),
> **массовое (оружие, пропсы, текстуры) добирается готовыми паками** и приводится к единому
> стилю утилитами (`retopo_conform.py`, `material_conform.py` — спринт 4).

**Правила:** Y-up (Blender) → Unity конвертирует; масштаб 1 unit = 1 м; пивот у основания/на рукояти;

## 3. Скрипты пайплайна (Blender 4.3.2 LTS, headless)

```bash
bash tools/build_models.sh all            # всё: оружие + персонажи + пропсы + стройка + транспорт
bash tools/build_models.sh transport      # только транспорт/лифт/вендинг (проверка решений)
bash tools/build_models.sh weapons --no-render    # быстро, без превью
```
| Файл | Что делает |
|---|---|
| `tools/blender/subs_common.py` | сцена, bmesh-примитивы (box/cylinder/cone/sphere/capsule/tube), PBR-материалы, UV, экспорт FBX/GLB, автоматический превью-рендер |
| `tools/blender/models_weapons.py` | оружие v4: ресиверы-оболочки с прорезанными окнами, планки Пикатинни, прицелы, сошки, магазины, гранаты/C4/РПГ (62 531 трис на 9 стволов) |
| `tools/blender/chars_hazmat.py` | хазмат-костюм (эталон качества персонажа) |
| `tools/blender/models_chars.py` | монстры всех типов + риг для персонажей |
| `tools/blender/models_props.py` | пропсы 3 уровней + строительный кит |
| `tools/blender/models_transport.py` | транспорт и «решения» опросника: самокат, тележка лута, вагонетка, кабина лифта, вендинг |
| `tools/blender/chars_trader.py` | торговец безопасной комнаты (`CH_trader_npc`) |
| `tools/provision_libs.py` | ставит системные библиотеки Blender без root (sysroot в `~/.cache`) |

**Итеративность:** меняешь число в Python — получаешь новую модель за секунды. Например,
`S.box("HZ_chest", (0.44, 0.26, 0.34), taper=(0.86, 0.94))` — и торс уже другой формы.

## 4. Импорт в Unity (автоматизированно)

`Subsistence → 1. Настроить проект` включает:
- **FBX Import Settings**: scale 1, «Bake Axis Conversion», generate colliders off (коллайдеры делаем вручную),
  LOD Group auto-setup, material search → `Assets/Subsistence/Materials/...`;
- **Материалы**: конвертация Principled → HDRP/Lit (Base Color, Metallic, Smoothness, Emission, Bump);
- **Префабы**: `WeaponPrefabBuilder` создаёт префаб оружия (модель + точки muzzle/scope/eject + hitbox-сокеты);
- **Монстры**: `MonsterPrefabBuilder` — модель + Hitbox-компоненты на голове/слабых точках + NavMeshAgent.

## 6. Как мы будем держать «ультра-хардкор» качество

1. **Единая плотность:** карта: ≤ 40 000 трис на «героя сцены» (игрок, босс), ≤ 8 000 — на всё остальное.
2. **Текстуры:** 4K на вид от первого лица, 2K на вид от третьего, 512–1K на дальние пропсы.
3. **LOD:** 3 уровня + Impostor для мелких предметов; `QualitySettings.lodBias` управляется настройками графики.
4. **Свет:** HDRP, объёмный туман, эмиссия на лампах, SSAO. Тени — только у ближних объектов (60 м).
5. **Материалы:** те же параметры в HDRP и в Blender (проверка через превью-рендер: цвет не должен «уезжать»).
6. **Приёмка:** скриншот 1:1 с референсом (у нас есть твои: коридоры, хазмат, оружие) и разница по силуэту ≤ 5 %.
