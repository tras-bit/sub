## 2. Что проверить в игре (галочки)

### Строительство (план + киянка)

- [ ] **Q** — палитра постройки: 12 элементов, цифры 1…0, «-», «=» переключают элемент.
- [ ] **ЛКМ** с планом застройки — твиг-блок ставится по сетке 3×3 м, тень превью зелёная/красная.
- [ ] **R** — поворот элемента на 90°.
- [ ] Взял **молоток**: над блоком появляется подсказка с прочностью и ценой.
- [ ] **ПКМ (тап)** по твигу — апгрейд `twig → wood`. В подсказке должно быть «мягкая сторона: к тебе».
- [ ] Ещё раз ПКМ — `wood → stone` (нужны камни 300 + дерево 100), потом `metal`, потом `armored` (HQM).
- [ ] **ЛКМ по блоку** молотком/оружием: урон идёт, у дерева и камня он слабый (RaidTable), по **мягкой** стороне бьёт ×2.5.
- [ ] Ударил свой блок → **ПКМ** — ремонт (+40% прочности за четверть цены).
- [ ] **Удержание ПКМ 2.5 с** по твигу — снос с полным возвратом. В подсказке идёт счётчик «осталось N с».
- [ ] Через 10 минут после постройки снос уже нельзя («только взрывчаткой»).
- [ ] **Шкаф (Tool Cupboard)**: без него база гниёт (decay), в чужом радиусе строительство запрещено.

### Верстаки (3 уровня, радиус 4 м)

- [ ] Поставил верстак 1 — в чате «Верстак 1 уровня рядом — крафт до 1 тира, скорость ×1 (чужой тоже подходит)».
- [ ] Открыл крафт (**Q** без плана или **E** на верстаке): в шапке панели видно уровень верстака и скорость.
- [ ] Рецепты 2–3 тира **серые**, пока нет верстака нужного уровня.
- [ ] Отошёл на 5+ метров — уровень верстака сбрасывается, рецепт заказать нельзя.
- [ ] **Апгрейда на месте нет** (ответ 1б): с верстаком 2 уровня в руках **E** на верстаке 1 даёт
      только подсказку «снеси киянкой и построй верстак 2 уровня» — верстак остаётся первым.
- [ ] Снос киянкой (удержание ПКМ) верстака 1 возвращает ресурсы, ставишь верстак 2 — он выше и быстрее.
- [ ] Крафт в очереди идёт быстрее у верстака выше тира (×1 / ×2 / ×3).

### Технологическое дерево (1.0.0-alpha)

- [ ] Крафт показывает у неизученных рецептов пометку: `изучить: 310 хлама`.
- [ ] Попытка скрафтить неизученное → понятное сообщение: «нужен стол исследований, N хлама и верстак M уровня».
- [ ] Поставил **стол исследований** (`research.table`), подошёл → открывается меню со списком.
- [ ] В шапке меню видно: «Изучено: N/180 · хлам: X · верстак рядом: M уровня».
- [ ] Пункты серые, если не хватает хлама или тира верстака; у недоступных — «нужен верстак N».
- [ ] Цифры 1–9 изучают предмет, звучит `research_done` (три тона + шорох), прогресс растёт.
- [ ] Быстрый путь: держишь предмет в руках, E на столе → изучение без открытия меню.
- [ ] Базовые рецепты (план застройки, топор, кирка, лук, верстак 1, печь) доступны **сразу**, без изучения.
- [ ] T2-предмет не изучается у верстака 1 — пишет «нужен верстак 2 уровня».
- [ ] Модели верстаков: T1 деревянный стол с тисками, T2 стальной со сверлильным станком, T3 с токарным узлом.

### Стройка: 15 элементов (ответ 9в) и модели всем «кубовым» (10а)

* [ ] Q — палитра: **15 строк** (было 12). Клавиши: `1-9`, `0`, `-`, `=`, `[`, `]`, `\`.
* [ ] `[` — **рампа-угол**: подъём по диагонали в угол клетки + площадка сверху.
* [ ] `]` — **перила**: перекладины и балясины, HP 60 % от стены, стоит 15 дерева.
* [ ] `\` — **ставни**: рама с 9 ламелями, HP 80 % от стены, стоят 15 дерева.
* [ ] Крыша (клавиша `9`) — теперь скат с коньком и стропилами, а не квадрат.
* [ ] Высокая стена (`-`) — 3×6 м в два пояса (было 3 м).
* [ ] Столб (`=`) — 0.36×3 м с базой и оголовком.
* [ ] Треугольные фундамент/перекрытие (`2`, `7`) — скос 45°, а не квадрат.
* [ ] Пандус (`0`) — настил 3 м, подъём 1.5 м, бортики видно.
* [ ] Все модели лежат в `Assets/Subsistence/Models/Props/BD_*.fbx` (превью: `docs/previews/_sheet_buildpieces.png`).

### Верстаки: без апгрейда, скорость ×1/×2/×3, палитры по уровням (ответы 1б, 3в, 4а, 5в)

* [ ] На верстаке **нет** кнопки «улучшить» (1б): подошёл с верстаком 2 уровня в руках —
      игра пишет «апгрейда на месте нет: снеси киянкой и построй верстак N уровня».
* [ ] Снос киянкой возвращает ресурсы в течение 10 минут (8а), потом только лом.
* [ ] Скорость крафта (3в): у верстака 1 — ×1, у 2 — **×2**, у 3 — **×3** (в тосте и в палитре).
* [ ] Чужой верстак (4а): крафтится так же, как свой, — в тосте «(чужой тоже подходит)».
* [ ] Палитры (5в): поставь верстак 1 уровня в коридорах, в бассейнах и на станции — три
      разных вида (тёплое дерево / серо-бирюзовый / тёмный промасленный). Лист: `_sheet_workbench_levels.png`.

### Свои уровни, лут, палитры

- [ ] **L0 (коридоры)**: жёлтые обои, ковролин, потёки, гудят лампы; в ящиках — светогриб, скотч, план.
- [ ] **L37 (бассейны)**: бирюзовый пар, кафель, вода; в локерах — **маска ныряльщика**, в медшкафах — **хлорка**.
- [ ] Надел маску и нырнул: под водой держишься ~11 с (без маски 5 с), урон слабее.
- [ ] Хлорка + грязная вода на верстаке 1 → чистая вода (x2).
- [ ] **L3 (электростанция)**: гарь, темнее, чем в коридорах; в щитах — **диэлектрические перчатки**, в сейфах — **силовой предохранитель**.
- [ ] Перчатки надеты — Искровик бьёт током на четверть (без них — больно).
- [ ] Туман и свет **меняются при переходе между уровнями** (плавно, ~1.5 с), а не одинаковые везде.
- [ ] Монстры по уровням: L0 — Улыбающийся + **Шептун** (шёпот-манить), L37 — Гончая + **Утопленник** (мокрые шаги) + Патигуер, L3 — Свежеватель + **Искровик** (треск).

### Свои предметы уровней: по 4 на уровень (ответ 11а)

* [ ] L0: **светогриб**, **скотч**, **лампа-переноска**, **респиратор** — только в коридорах.
* [ ] L37: **маска ныряльщика**, **хлорка**, **ласты**, **кислородный баллон** — только в бассейнах.
* [ ] L3: **диэлектрические перчатки**, **силовой предохранитель**, **резиновые сапоги**,
      **изолированный ключ** — только на станции.
* [ ] Вещи уровней не пересекаются: в луте коридоров нет ласт, в бассейнах нет сапог.
* [ ] Превью моделей: `docs/previews/_sheet_levelitems.png` (12 предметов, у каждого своя модель).
* [ ] **Крафт**: у каждого из 12 предметов есть рецепт на «своём» верстаке (L0 → верстак 1,
      L37 → верстак 2, L3 → верстак 3). Хлорка варится из хлорированной воды на верстаке 2.
* [ ] **На полу**: выброси светогриб/скотч/маску/перчатки или АК — лежит своя модель, а не куб.

### Звук (1.0.0-alpha — процедурный, файлов нет, музыки/радио нет по ответу 16а)

- [ ] **Фон уровня**: в коридорах слышен ровный гул ламп; в бассейнах — тишина с водой;
      на станции — низкое гудение трансформатора. При переходе между уровнями фон меняется.
- [ ] **Шаги**: по ковролину глухие, по кафелю звонче; по воде — «чавк» (мокрый шаг).
- [ ] **Монстры**: Шептун — шёпот раз в ~16 с (иди на звук — там он); Утопленник — мокрые
      шаги; Искровик — треск и разряды. По звуку понятно, кто рядом, ещё до того как увидел.
- [ ] **Погоня**: рычание каждые 2.6 с (Гончая) / 4.2 с (остальные); при смерти — крик.
- [ ] **Оружие**: выстрел с раскатом (у снайперки громче), перезарядка — три металлических
      щелчка, попадание по мясу / по металлу — разные.
- [ ] **Стройка**: стук при постановке блока, звонкий удар при апгрейде, три постукивания при
      ремонте, обвал при сносе.
- [ ] **Лут/крафт**: тихий «бульк» при подборе, «динь-динь» по завершении крафта.
- [ ] Звуки не щёлкают на петле фона (стык сглажен окном Ханна 0.2 с).

### Анимация монстров (процедурная)

- [ ] Монстр **покачивается при ходьбе** (bob, крен, наклон вперёд), в покое «дышит».
- [ ] При погоне движения резче (амплитуда ×1.4) — видно, что несётся.
- [ ] Искровик **дрожит** (речь о высокочастотном jitter меша).
- [ ] Утопленник валится с боку на бок, Шептун крадётся, подавшись вперёд.
- [ ] При смерти монстр **заваливается на 82°** и оседает (а не исчезает стоя).
- [ ] Модель и коллайдер не разъезжаются: анимируется только визуальный меш.

## 3. Собрать exe

**Вариант A (батник):** `BUILD_WINDOWS.bat` → находит Unity 2022.3.62f2 → собирает
`Builds\Windows\Subsistence.exe` (5–20 мин, лог в `build_log.txt`).

**Вариант B (в Unity):** меню **Subsistence → 9. Собрать всё и билд** или **→ Собрать Windows-билд**.

**Если exe не появился:** батник сам проверит лог. Самая частая причина — Unity без лицензии:
тогда он напишет про аккаунт Unity Hub и предложит режим `BUILD_WINDOWS.bat play`
(открыть редактор и играть прямо в нём — для проверки хватает).
