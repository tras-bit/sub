# SUBSISTENCE — сборка Windows-билда

**Версия:** 0.1.0 · **Unity:** 2022.3.62f2 LTS (строго) · **Рендер:** HDRP 14.0.12 · **Сеть:** опционально (Mirror v96)

## Запуск — 3 шага, в меню лезть не надо

1. Распаковать архив.
2. Unity Hub → **Add project from disk** → **сама распакованная папка**: она уже Unity-проект
   (внутри сразу `Assets\`, `Packages\`, `ProjectSettings\` — ничего перекладывать не нужно).
3. Открыть проект и подождать 1–3 минуты. Unity **сам**: настроит слои/теги/физику, создаст
   HDRP-ассет, соберёт префабы 159 моделей, сгенерирует сцену `Levels.unity`, экспортирует
   `items.json`, прогонит диагностику и **откроет сцену**. В Console: `[Subsistence] ГОТОВО… жми Play.`

Дальше — просто **Play**. Автонастройка живёт в `Editor/AutoSetup.cs`, срабатывает один раз
(маркер `ProjectSettings/Subsistence.autosetup`). Повторить вручную: **Subsistence → 0. Автонастройка проекта**.

## Собрать .exe

- **Из редактора:** `Subsistence → Собрать Windows-билд` → `UnityProject\Builds\Windows\Subsistence.exe`.
- **Без редактора:** двойной клик по `BUILD_WINDOWS.bat` (нужна установленная 2022.3.62f2) → тот же результат + лог `build_log.txt`.
  Батник сам понимает, где проект: ищет `ProjectSettings\ProjectVersion.txt` рядом с собой или в подпапках.

## Вариант «вручную в редакторе» (если автонастройку отключишь)

1. Установи **Unity Hub** → *Installs* → **2022.3.62f2 (LTS)** с модулем **Windows Build Support (IL2CPP/Mono)**.
2. Дважды кликни **`BUILD_WINDOWS.bat`** в корне распакованного архива.
   Если Unity не нашёлся — перетащи мышкой `Unity.exe` на `.bat`, либо:
   `BUILD_WINDOWS.bat "C:\Program Files\Unity\Hub\Editor\2022.3.62f2\Editor\Unity.exe"`
3. Скрипт сам выполнит: настройку проекта → items.json → HDRP Asset → префабы моделей →
   сцену → диагностику → **Windows-билд**. Первый прогон идёт 10–25 минут (Unity качает
   пакеты HDRP/Burst/Addressables).
4. Результат: `UnityProject\Builds\Windows\Subsistence.exe` (папка откроется сама).
   Полный лог: `build_log.txt`.

Он же умеет то же самое из консоли:

```bat
Unity.exe -batchmode -quit -projectPath "ПУТЬ\UnityProject" -buildTarget StandaloneWindows64 ^
          -logFile "build_log.txt" ^
          -executeMethod Subsistence.EditorTools.ProjectBootstrap.BuildAll
```

## Вариант 2 — вручную в редакторе Unity

1. **Unity Hub → Open →** корень архива (в исходнике — папка `UnityProject`) — версия 2022.3.62f2. Дождись импорта пакетов
   (в `Packages/manifest.json` уже прописаны HDRP 14.0.12, Burst, Collections, Mathematics,
   Addressables, Input System, Timeline, uGUI).
2. Прогони меню **`Subsistence`** сверху вниз:

| Пункт | Что делает | Обязательно |
|---|---|---|
| **0. Автонастройка проекта** | весь конвейер (1→4→5→7→2→6) одной кнопкой — то же, что происходит само при первом открытии | = |
| **1. Настроить проект** | слои 6–16, теги, физика, цветовое пространство, Input System = *Both* | да |
| **5. Создать HDRP Asset + назначить** | `Assets/Subsistence/Settings/HDRP_Subsistence.asset` → Graphics/Quality | да |
| **7. Модели: префабы и Resources** | 159 FBX → `Resources/Models/*.prefab` + отчёт | да |
| **2. Создать мир (сцена)** | `Assets/Subsistence/Scenes/Levels.unity` + Build Settings | да |
| **4. Экспорт items.json** | баланс предметов в `StreamingAssets` (правится без пересборки) | желательно |
| **6. Проверка проекта** | диагностика в консоль (что не настроено) | по желанию |
| **3. Включить Mirror** | define `MIRROR` + установка пакета с GitHub — **только для сетевой игры** | нет |
| **8. Проверить модели (отчёт)** | список моделей и их габаритов | нет |
| **Собрать Windows-билд** | `Builds/Windows/Subsistence.exe` | да |
| **9. Собрать всё и билд (одним кликом)** | весь конвейер целиком (= то, что делает `.bat`) | = |

3. После пункта **5** Unity откроет **HDRP Wizard** — нажми там **«Fix All»** (он настроит
   объёмный свет, туман, shadow-настройки). Это одна ручная кнопка, которую скрипт нажать не может.
4. Нажми **Play** — должна пойти **зелёная консоль загрузки** (`C:\SUBSISTENCE>`) и
   процедурная генерация уровня (seed 1337).

## Что происходит при первом запуске игры

- Загрузка: BIOS-терминал, строки «загрузка starts», OK-статусы всех систем (HDRP, Mirror/Local,
  инвентарь, крафт, стройка, лут, монстры, транспорт, погода, айрдропы).
- Уровень 1 «коридоры» (жёлтые обои, решётчатые лампы), уровни 2 «бассейны» и 3 «электростанция» —
  переходы лифтами по ключ-картам.
- Лут 3 тиров по уровням, респавн 5/15/30 мин (по тиру ящика), айрдропы 900–1680 с.
- Управление: WASD, Shift — бег, C — присед, ЛКМ — огонь, ПКМ — прицел, R — перезарядка,
  E — взаимодействие, Tab — инвентарь/крафт, B — палитра строительства.

## Честно про статус сборки

- Код **никогда не компилировался**: в песочнице нет ни Unity, ни C#-компилятора. Проверки были
  только текстовые (баланс скобок, поиск вызовов без объявления, сверка сигнатур) — они чистые,
  38 `.cs` / ~14 900 строк.
- Поэтому **первый прогон может выдать 1–3 ошибки компиляции**. Если так — пришли текст из
  `build_log.txt` (строки `error CS…`), поправлю в следующем архиве. Это ожидаемо и лечится быстро.
- Сетевая игра (Mirror) выключена по умолчанию — игра запускается офлайн. Включение: пункт меню 3.
- Модельки генерируются скриптами Blender (`tools/`) — их можно пересобрать и перегенерировать
  в любой момент: `bash tools/build_models.sh all`.
