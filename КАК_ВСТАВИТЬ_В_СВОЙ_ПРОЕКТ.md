# Как «закинуть» игру в Unity

## Вариант A — проще всего (ничего никуда кидать не надо)

1. Распакуй архив куда угодно, напр. `D:\Games\Subsistence`.
2. **Unity Hub → Add → Add project from disk →** укажи **корень распакованной папки**
   (ту, где сразу лежат `Assets\`, `Packages\`, `ProjectSettings\` — в 1.0.0-alpha проект
   лежит в корне архива, искать `UnityProject` не нужно).
3. Открой проект (Hub сам потребует 2022.3.62f2).
4. Меню сверху **Subsistence**: `1` → `5` (в HDRP Wizard нажать **Fix All**) → `7` → `2`,
   затем `Subsistence → Собрать Windows-билд` — или просто жми **Play**.

Это целый готовый проект со своими `Packages/manifest.json` и `ProjectSettings`.
Кидать его «в другую игру» не нужно — он открывается сам по себе.

## Вариант B — у меня уже есть свой Unity-проект, хочу игру внутрь него

Копируй **только** это (и **не** копируй `ProjectSettings`):

```
архив/UnityProject/Assets/Subsistence/   ->   твой_проект/Assets/Subsistence/
```

Дальше:

1. Открой `твой_проект/Packages/manifest.json`. **Не заменяй файл целиком** — потеряешь свои пакеты.
   Допиши в блок `"dependencies": { ... }` строки из `extras/manifest_snippet.json` (ровно нужные
   версии). Следи за запятыми: у последней строки запятой нет.
2. Открой проект в Unity 2022.3.x, дождись импорта пакетов и моделей.
3. Меню **Subsistence**: `1. Настроить проект` (слои 6–16, теги, физика, Input = Both) →
   `5. Создать HDRP Asset` → в открывшемся **HDRP Wizard** нажать **Fix All** →
   `7. Модели: префабы` → `2. Создать мир (сцена)`.

### Важно, иначе не заработает

- **Нужен HDRP.** Игра использует High Definition RP 14.0.12. Если твой проект на Built-in RP или URP —
  либо переключи на HDRP (Project Settings → Graphics + Quality → ассет из пункта 5), либо бери Вариант A.
- **Версия Unity: 2022.3.x** (в архиве ровно `2022.3.62f2`). В Unity 6000.x проект «обновится», HDRP
  уедет на 17.x и часть настроек может поехать.
- **Слои 6–16 и теги** создаёт пункт `1`. Если они уже заняты в твоём проекте — сверься с
  `Edit → Project Settings → Tags and Layers`.
- **Не копируй `Library/`, `Temp/`, `obj/`, `Builds/`** — их Unity создаёт сама.

## После этого (оба варианта)

**Play** → пойдёт зелёная консоль загрузки (`C:\SUBSISTENCE>`) и процедурная генерация уровня (seed 1337).
Управление: WASD, Shift — бег, C — присед, ЛКМ — огонь, E — взаимодействие, Tab — инвентарь/крафт, B — стройка.

Если на первом импорте/сборке вылезут 1–3 ошибки `error CS` — это ожидаемо (код в песочнице не
компилировался): пришли строки из консоли или `build_log.txt`, поправлю и пересоберу архив.
